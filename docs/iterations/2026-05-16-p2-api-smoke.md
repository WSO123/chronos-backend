# Iteration: P2 API Smoke Coverage

日期：2026-05-16
阶段：P2 目标与洞察增强
状态：Implemented

## 1. 背景

P2 已经新增较多接口，仅靠单测不够直观验证“目标 -> 今日 -> 执行 -> 报告 -> 洞察 -> Me”的串联路径。需要一个脚本级 smoke，方便每轮迭代后快速检查 P2 合同是否仍然可用。

## 2. 目标

- 新增 P2 API smoke 脚本。
- 串起 Goals、Task Priority、Dependency、Today Preview、Strategy Detail、Goal Detail、Timeline、Weekly / Monthly Report、Insight Detail、Me Overview。
- 每次使用独立 smoke 用户，不重置数据库。

## 3. 非目标

- 不替代单元测试。
- 不覆盖 P3/P4。
- 不做性能压测。

## 4. 新增脚本

```bash
uv run python scripts/smoke_p2_goal_insight_loop.py
```

脚本默认创建独立用户：

```text
smoke-p2+YYYYMMDDHHMMSS@chronos.local
```

## 5. 覆盖链路

```text
Create Goal
-> Create Tasks
-> Adjust Priority
-> Add Dependency
-> Get Today / Strategy
-> Focus Complete
-> Goals Home
-> Goal Detail
-> Goal Progress Timeline
-> Weekly Report
-> Monthly Report
-> Insight Detail
-> Me Overview
```

## 6. 验收标准
